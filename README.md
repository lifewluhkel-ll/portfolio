# 张陈夷｜新媒体运营 · 品牌内容策划作品集

面向新媒体运营、品牌内容策划岗位的个人作品集网站，呈现内容策略、脚本分镜、视频制作、投流创意与视觉叙事能力。

## 内容包括

- 15 条精选视频作品，可在网页内直接播放
- 7 份项目 / 策略案例 PDF，可在网页内预览
- 简历下载、能力说明与横向作品浏览交互

## 本地预览

直接打开 `index.html`，或在本地静态服务器中运行本站。

## GitHub Pages

推送至 `main` 分支后，`.github/workflows/deploy-pages.yml` 会自动部署站点。请在仓库 **Settings → Pages** 中将 Source 设为 **GitHub Actions**。

## 媒体说明

仓库保留网页实际使用的 15 条视频，并已转换为适合浏览器播放的 H.264 / AAC 轻量版本，以符合 GitHub 的单文件限制并保证加载体验。原始高清视频不纳入仓库。
